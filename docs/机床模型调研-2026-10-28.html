1.3 运动学公式（5axiskins.c 原文实现）

设 R = pivot_length + tool_length + W：

r = ( R·sin(B)·cos(C),  R·sin(B)·sin(C),  −R·cos(B) )     // 枢轴→刀尖

刀尖：  X_tip = X + r.x
        Y_tip = Y + r.y
        Z_tip = Z + pivot + tool + r.z

逆解就是减掉 r。B、C 由程序直接给出，X/Y/Z 是刀尖坐标——即内建 RTCP。

两个必须注意的点：

  1. 符号约定与常规相反。源码注释原文："The direction of the tilt axis is the opposite of the conventional axis direction." 我们的 Joint::sign 字段正是为此存在——但具体填 +1 还是 −1 必须用往返测试锁定，不能凭公式推。
  2. 这是"虚拟"BC，不是物理轴。vismach 里 B 的物理回转轴是 (1,0,−1)（45° 万向头），而 kins 用的是球坐标的极角。仿真器只需要从程序给出的 B/C 算出刀位——物理 45° 轴怎么实现是控制器的内部事务。

2.1 三个必须知道的事实

  1. 没有一个是五轴的。搜 5 axis cnc / trunnion / machining center 都没有可下载的五轴整机。最接近的是三轴台式机。
  2. 全部是 CC-BY，要求署名。不是 CC0，所以界面上要标作者。
  3. 我拿不到文件本体：Sketchfab 下载需要登录账号（OAuth token）。API 只给元数据和缩略图，isDownloadable: true 指的是"登录后可下"。

所以"精美"这一项我没能直接交付文件，只能交付清单 + 直链。 你自己登录点下载即可，三个都是 CC-BY，自用没问题。

三、两者怎么合起来

这两件事天然分离，正好对应 ADR-007 的"三种表示"：

运动学参数  ←  LinuxCNC 5axiskins.c + 5axis.ini   （参数齐全，精确）
显示外形    ←  Sketchfab 模型                      （精美，但尺寸不一定准）
碰撞代理    ←  按实测尺寸手填的 OBB                 （保守，与外形无关）

关键：不要把 Sketchfab 模型的尺寸当成真机尺寸。 那些是美术模型，比例随作者心情。所以：

  • Shape::Gltf { node } 挂上去做外观
  • collider: Explicit(...) 手填实测 OBB
  • 运动学只认 5axis.ini 的数

这样"精美"和"准确"各得其所——观感可以妥协，正确性不行。

附：一个可以立刻做的验证

5axis.ini 的 SERVO_PERIOD = 1000000 说明插补周期是 1 ms。这直接印证了 ADR-004 §3.1 的穿透风险估算：

  • 直线轴 200 mm/s × 1 ms = 0.2 mm/周期
  • 旋转轴 60 °/s × 1 ms = 0.06 °/周期

所以这套参数下，快移穿透薄壁的风险比我原来估的（100 m/min = 1.67 mm/ms）小一个数量级——保守推进仍然是必需的，但压力没那么大。这个数应该写进配置，而不是写死在代码里。
