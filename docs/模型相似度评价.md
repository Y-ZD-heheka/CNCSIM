# 模型相似度：算法谱系 + 我们该补哪些

> 日期：2026-11-06
> 结论：**"像不像"不是一个数。距离类管最坏点，体积类管整体，法向类管朝向，计量类管验收。**
> 我们缺的是"双向"和"朝向"，不是更花哨的算法。

---

## 0. 一句话结论

| 类别 | 代表指标 | 我们 | 该不该加 |
|---|---|---|---|
| 距离·单向 | 名义面逐点有符号偏差 | ✅ 有 | — |
| 距离·双向 | Chamfer / Hausdorff | ✅ **本轮加了** | — |
| 距离·分半 | F-score@τ（P/R） | ✅ **本轮加了** | — |
| 体积 | 过切/残料体积 | ✅ 有 | — |
| 体积·归一 | IoU / Dice | ✅ **本轮加了** | — |
| 朝向 | 法向一致 | ✅ **本轮加了** | — |
| 方向偏置 | `bias`（正=过切） | ✅ **本轮加了** | — |
| 计量·形位 | 平面度/圆柱度（最小区域法） | ✅ **本轮加了** | — |
| 计量·轮廓度 | ISO 1660 公差带 | 部分（±tol 统计） | 按特征分组即可 |
| 计量·粗糙度 | ISO 25178 Sa/Sq | ❌ 无 | **不该加**（分辨率不够） |
| 配准 | ICP / Go-ICP / FGR | ❌ 无 | **不该加**（会吃掉装夹误差） |
| 学习类 | 特征距离 / LPIPS | ❌ 无 | **不该加**（不可解释） |

## 1. 算法谱系

### 1.1 距离类：点到面 vs 点到点

我们用的是**距离场**（`sdf`），本质是"点到最近面"的欧氏距离，比"点到最近采样点"准——
后者受采样密度影响，前者不受。这一点常被忽略：拿顶点集算 Chamfer 时，结果会随
三角化密度变化，而我们的 `surface_dev` / `similarity` 都是点到面。

| 指标 | 定义 | 抓什么 | 盲区 |
|---|---|---|---|
| MDE / RMS | 单向平均 / 均方根 | 整体偏移 | 极值被平均掉 |
| Chamfer | `½(mean_{a∈A}d(a,B) + mean_{b∈B}d(b,A))` | 双向平均，整体像了多少 | **不是度量**（无三角不等式），大偏差被面积摊薄 |
| Hausdorff | `max(sup_a d(a,B), sup_b d(b,A))` | 最坏点：干涉、装配过盈死在这一处 | 单点极值，对离群极敏感；不看面积 |
| F-score@τ | `2PR/(P+R)`，P/R 为 τ 内的比例 | 分成"多出来的"与"漏掉的" | 依赖 τ，且**不含方向**（过切与残料都会让两者一起掉） |

关键：**F-score 不区分过切与残料**。两者都让"面偏离了名义位置"，P 和 R 一起下降。
方向必须靠**有符号距离**：`bias = ½(mean d_设计→实际 + mean d_实际→设计)`，正 = 过切。

### 1.2 体积类

| 指标 | 定义 | 特点 |
|---|---|---|
| 对称体积差 | `|AΔB|`（我们的过切 + 残料体积） | 绝对量，跨零件不可比 |
| IoU | `|A∩B| / |A∪B|` | 归一化，可跨零件比 |
| Dice | `2|A∩B| / (|A|+|B|)` | 与 IoU 单调等价，对小体积更敏感 |

体积口径**与采样密度无关**，但**对薄壁和曲面位移不敏感**：0.1 mm 的整体让刀在
3136 cm³ 的毛坯上体积几乎不动，装配上却致命。所以它只能当"整体像不像"的粗筛。

### 1.3 朝向类

- **法向一致**：对应点上 `|n_A · n_B|` 的面积加权平均。位置对但面被磨成斜面时，
  距离可能很小而法向一致明显掉。
- 曲率差 / 二面角分布：对"圆角 vs 尖角"敏感，但需要可靠的法向与曲率估计，
  在 h≈0.5 mm 的网格上噪声很大——**暂不做**。

### 1.4 配准类：为什么我们不用

ICP / point-to-plane ICP / Go-ICP / FGR / 4PCS 解决的是"**位姿未知**时把扫描件对齐到 CAD"。
我们的实际面和设计面**共用同一个坐标系**（仿真里没有装夹误差），配准会把
"装夹偏了 0.3 mm"这种真问题当成"没对齐"吸收掉——等于自欺。

唯一有用的变体是**特征级配准**：先把某个面单独对齐，再看它自身的形状误差。
这能分离"形状对不对"与"位置对不对"，但要**明确标注为诊断量，不作验收**。

### 1.5 学习 / 感知类：为什么不用

3D 特征距离、LPIPS、在 Chamfer 上训练出来的评价网络，都是给"重建/生成像不像"用的：
不可解释、不可追溯、阈值无物理意义。验证器的输出要能写进工艺卡，这类指标不行。

### 1.6 计量验收类：真正该对齐的口径

| 标准 | 内容 | 对我们的意义 |
|---|---|---|
| ISO 1101 | 形位公差（直线度/平面度/圆度/圆柱度…），评定用**最小区域法**（minimax），最小二乘会**高估**误差 | 想做"平面度 0.02"这种验收，必须实现 Chebyshev 拟合 |
| ISO 1660 | 面轮廓度：公差带 = 两张偏置面之间 | 就是我们的"过切/残料"，只是要继续按**特征**分组 |
| ISO 12180/12181/12780/12781 | 圆柱度/圆度/直线度/平面度 | 特征级指标的标准编号 |
| ISO 25178 | 面粗糙度：Sa/Sq/Sz/Sdq/Sdr… | **这个分辨率下无意义**，见 §4 |
| ISO 10360 | CMM 验收 | 提醒我们：测量系统本身要先标定 |

## 2. 我们现在的口径与盲区

已有的三层（见 `项目记忆.md` §27）：

1. 单向几何量：`Δz`（3 轴）/ `Δr`（回转）
2. 整实体体积：过切/残料体积 + 最大深度 + 包围盒 + 源行号
3. 名义面逐点有符号偏差：`sim::surface_dev`

盲区与补法：

| 盲区 | 后果 | 补法 |
|---|---|---|
| **只有单向** | 落在设计面之外很远的残料（从没被刀具碰过的方块）不会被任何设计面采样点看到 | 双向：实际面顶点 → 设计 SDF（`similarity::compare` 的反向一趟） |
| **没有朝向** | 平移 0.05 mm 与磨成斜面，逐点距离可能一样 | 法向一致（SDF 梯度 vs 网格法向） |
| **没有归一化** | 体积差无法跨零件比较 | IoU / Dice |
| **没有"最坏点"** | P95 好看但某个角超差 1.5 mm，装配装不进 | Hausdorff |
| **没有方向** | 过切 5% 和残料 5% 在合格率里长得一样 | `bias` + 已有 P/R 分解 |

## 3. 建议加的四项（按性价比）

| 优先级 | 指标 | 抓什么 | 成本 | 状态 |
|---|---|---|---|---|
| 1 | 双向 Hausdorff / Chamfer | 最坏点 + 双向平均 | 需一次网格提取（LOD1） | ✅ 已实现 |
| 2 | F-score@τ（P/R）+ `bias` | 面吻合程度 + 方向 | 同一次遍历 | ✅ 已实现 |
| 3 | IoU / Dice | 体积归一 | 逐体素，O(域) | ✅ 已实现 |
| 4 | 法向一致 | 朝向错 | 3 次 SDF 求值/顶点 | ✅ 已实现 |
| 5 | **特征级形位公差**（平面度/圆柱度，最小区域法） | "这个面平不平" | 需特征分割 + minimax 求解 | ✅ 已实现（`sim::form`） |
| 6 | **按特征分组的轮廓度**（ISO 1660） | "哪个特征超差" | 复用 `reach` 的连通块分组 | ⬜ 下一步 |
| 7 | 理论残高（scallop）与实际残高对比 | 刀路参数对不对 | `p²/(8R)` 与实际场比 | ⬜ 可选 |

**不建议加**：ISO 25178 粗糙度（分辨率差 2–3 个数量级）、EMD（O(n³)，无额外信息）、
全局 ICP（吃掉装夹误差）、学习类指标（不可解释）。

## 3.5 形位公差怎么做（`sim::form`）

形位公差不是"最大偏差"，是**包容区域的宽度**：

```text
平面度 = max(n·q) − min(n·q)      （两张平行平面把实际表面夹住的最小间距）
圆柱度 = max(r_i) − min(r_i)      （两个同轴圆柱的壁厚差；R 被消掉）
```

基准本身要**优化**——ISO 1101 以最小区域为准。实现是**八方向模式搜索**：
在单位球面上沿 ±e₁ / ±e₂ / 四条对角方向试探，改进不足千分之一就缩步长。

表面点从设计面采样沿**实际场梯度**投影到实际表面：`q = p + d·∇d/|∇d|`。
`d` 是到实际面的有符号距离、梯度指向最近点，所以这是一阶精确投影，
不需要最近邻搜索。

### 四个真坑（都有测试钉住）

| 坑 | 现象 | 处置 |
|---|---|---|
| 坐标下降卡在折点 | 只沿 ±e₁/±e₂ 走，四个方向都不降而**对角方向能降** → 停在比真解差 **0.36%** 的地方（被"随机撒 400 个方向"的测试抓出来） | 加四条对角方向；改进 < 0.1% 也缩步长 |
| 平面被判成半径无穷大的圆柱 | 轴挪得越远，平面上一片的到轴距离越接近常数（极差 ∝ w²/2R → 0），形式上"很像圆柱" | 三条否决：轴不许跑出特征 2.5×包围盒、`mz ≤ 0.05R`、角向覆盖 ≥ 4/12 扇区 |
| 一阶径向波动当成形状误差 | `r = R + a·cosθ` 只要把轴平移 a 就完全消掉——那是**偏心**（位置误差），不是形状误差 | 单测钉住：一阶波动 → 圆柱度 ≈ 0；二阶（椭圆）才计入 |
| 区域宽度写成"最大偏差" | 单点凸起 h 会被算成 h/2（若取"到中面的最大距离"）或 2×（若乘 2） | 单测：棋盘双层 h → 平面度 = h |

### 实测（桌腿件，11 道工序）

| h | 特征 | 面积 | 形位（MZ） | LSQ | 平均偏差 |
|---|---|---|---|---|---|
| 1.5 | 平面 | 2709 mm² | 0.621 | 0.664 | −0.031 |
| 1.5 | 平面 | 1634 mm² | 0.516 | 0.519 | −0.061 |
| **0.6** | 平面 | 2709 mm² | **0.028** | 0.029 | −0.024 |
| 0.6 | 平面 | 1634 mm² | 0.360 | 0.362 | −0.037 |

两件事值得注意：

1. **h=1.5 时平面度 0.62 ≈ 0.4h**，全是体素离散化；h=0.6 掉到 **0.028**——不是线性下降，
   因为形位是**相对基准的区域宽度**，平滑区域的量化噪声大部分互相抵消。
   所以形位公差比"逐点 |d|"灵敏得多，但也更容易被单个毛刺顶起来。
2. 同样 h=0.6，第二个面仍是 **0.360**：同一件活上不同面的平面度差一个数量级，
   这正是"整件一个数"看不出来的东西。

### 已知限制

- **特征分割是粗分**：位置连通 + 法向 12° 一致。曲率大的圆柱会被拆成条带
  （格距 3.75 mm 在 r=10 上就是 21.5° 的法向差），退化成"自由曲面"。
  阈值放到 24° 能连上圆柱，但会把 90° 的相邻面并成一片（自由曲面占比 39% → 55%）。
  两头都不划算，要同时成立得做**按曲率自适应**——没做。
- 报 `Freeform` 的面积不评形位，只报偏差统计（诚实：分不出特征就不该给公差号）。
- 圆柱的 4 参数搜索给的是**上界**（更细的搜索只会更小）。

## 4. 读数纪律：先标定测量系统

任何相似度指标都要先回答"**它自己准到哪**"。做法是**同一块料自比**：

| 口径（h=0.5，盒形试件） | 自比读数 | 含义 |
|---|---|---|
| Hausdorff | **0.177 mm** | 棱边处顶点偏离 h/√2 → 峰值被离散化主导 |
| Chamfer | **0.006 mm** | 平均值几乎为 0 |
| F1@0.15 | **0.9989** | 99.9% 的点在公差带内 |
| IoU | **1.0000** | 体积完全一致 |
| 法向一致 | **1.000** | — |

推论（重要）：

1. **Hausdorff 的可用下限 ≈ 0.35h**，与 `tol` 无关。报 `tol=0.15` 却给 0.177 的底噪，
   等于在噪声里找信号。
2. **Chamfer 与 F1 才是可比量**——它们的底噪比 Hausdorff 低两个数量级。
3. 判据应满足 `tol ≥ 2h`；要 0.05 mm 级判据，必须 `h ≤ 0.25`（仿真时间 ×8 起）。

### 实测量级（桌腿件，11 道工序）

| h | Hausdorff | Chamfer | F1@0.15 | IoU | 法向一致 | bias |
|---|---|---|---|---|---|---|
| 1.5 | 3.481 | 0.157 | 0.807 | 0.9759 | 0.993 | −0.009 |
| 0.6 | 2.419 | 0.109 | 0.855 | 0.9791 | 0.987 | −0.043 |

h 从 1.5 降到 0.6，Chamfer 降 31%、F1 升 4.8 点，而 Hausdorff 只降 30%——
**Hausdorff 主要由细小的台阶/棱边决定，与"整体做像了多少"关系不大**，这也解释了
为什么不能只看它。

## 5. 实现与接口

`crates/sim/src/similarity.rs`：

```rust
let s = cncsim_sim::similarity::compare(&design, &samples, &grid, domain, &mesh, 0.15);
// s.hausdorff / s.chamfer / s.f_score / s.precision / s.recall
// s.iou / s.dice / s.normal_consistency / s.bias_mm / s.verdict()
```

- 正向：设计面采样（面积加权）→ 实际场 `sdf`
- 反向：实际面网格顶点 → 设计 `sdf`
- 体积：逐体素判"设计实心 / 实际实心"
- 钳制：`DesignModel::Field` 的距离上限是 `band`，被钳住的点数单独报
  （`design_saturated` / `actual_saturated`），非零时 `hausdorff` 只是**下界**

三条测试各自钉住一个结论：

| 测试 | 钉住什么 |
|---|---|
| `identical_parts_score_near_perfect` | 度量本身的底噪（H 0.177 / Chamfer 0.006 / IoU 1.0） |
| `a_leftover_block_is_only_visible_from_the_reverse_direction` | **反向不可省**：正向 `design_max` < 1 mm，反向 `actual_max` > 12 mm |
| `a_gouged_face_shows_a_positive_bias` | `bias` 的符号：顶面少切 1 mm → `bias > 0` |
